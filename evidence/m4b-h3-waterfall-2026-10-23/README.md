# H3 memory-waterfall reducer — initial host implementation

**Status: host reducer implemented; no complete real-run waterfall produced.** The observed post-boot CMA state is high, but runtime remains `HOLD_RUNTIME` because allocation classes, peak overlap and independent safety reserve are unqualified. No device launch or reboot was performed for this H3 work.

## Implementation

`tools/peak_memory_waterfall.py` reuses `ledger_bases.replay_texture_budget()` for owned budget/GL-storage/owner-event replay and `cma_readonly_compare.compare_snapshots()` for same-boot CMA order/process comparison. It accepts a run log, identity-pinned process timeline, two or three CMA snapshots, a harness identity, and a filtered kernel-warning delta bundle.

The output keeps separate ledgers for logical guest/budget bytes, per-window CPU BC/other staging requests, nominal GL storage, process pages, DMA-BUF inventory and CMA free orders. It does **not** sum them. Per-window requested peaks are reduced by maximum, not addition. M3B decode, GL-allocation and upload subintervals and per-event size/subresource fields are preserved. A valid first `phase=prelaunch` record (`seq=-1`, `pid/starttime=null`, not running) is retained as `prelaunch_system`, excluded from the runtime process ledger and process/time joins; invalid or misplaced prelaunch records fail closed. `owner-generation` equal to `owner-id` with basis `nvn-object-id` remains raw; semantic generation stays unknown until the exact run ELF and matching source tree are independently verified. Available local build-262–266 source copies did not match the candidate receipt's tree digest, so none was accepted as its source. For `nvn-object-id`, an owner-ID/value mismatch makes the M3B capture incomplete. `storage-generation` remains separate. `T2_MEMWATCH_SAMPLE` has no monotonic timestamp in its current schema, so it is retained as `unjoined_no_timestamp`; `present_serial` is explicitly unobserved when the source record does not emit one. Kernel warning deltas stay system-wide, not process-attributed. Fileback mirror, EGL/GBM/display backing, movable-page occupancy, pinned CMA and Mali-private physical bytes remain `unknown` unless supplied by evidence. DMA-BUF exporter size is not converted to CMA bytes, and promotion is never inferred from this reducer.

Fail-closed checks include mixed run/process identity, reordered timeline timestamps, missing 64 MiB floor samples, incomplete M3B/owner rings, late ID280/ID288 pairs through the existing ledger replay, and malformed subresource counts. Unknown GPU completion and physical backing prevent promotion. Local input files are bounded, checked for stability during read, and SHA-256 tagged in CLI output.
